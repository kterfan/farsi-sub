# Changelog (English)

English notes start with 1.8.0. The complete history, in Persian, is in
[CHANGELOG.md](CHANGELOG.md).

## 1.8.0

- **A new, more professional look in every window:** icons on every button, grouped
  button segments, on/off switches instead of tick boxes, coloured status pills in the
  queue, arrows on every drop-down, and a soft tint for the selected row instead of a
  solid blue band.
- **No button is ever hidden in a small window.** The editor's toolbar used to put
  whatever did not fit behind a small overflow arrow. Now the labels of the less
  important buttons are dropped first (the icon stays, the name moves to the tooltip),
  and if that is still not enough the buttons wrap onto a second line. The main window
  works the same way.
- **Editor:** a header with the file name, the line number and the count of doubtful
  words (click it to jump to the next one); *Save* and *Video with subtitle* at the top;
  a round play button under the picture; a waveform with grips on the draggable edges.
- Settings window: each section's title sits above its card instead of on its border;
  *Save* is highlighted.
- The engine chip no longer reads "10 models" for one model (a middle dot next to a
  Persian digit looked like a zero).
